# Safety notice

> [!WARNING]
> **DON'T RUN YOUR PRINTER ON THESE SETTINGS.** All example settings and calibration data are invented for conformance tests.

This repository is software documentation and testing data, not hardware operating advice. It does not provide safe machine G-code, nozzle/extrusion limits, heat limits, motion limits, or filament processing specifications. Always obtain validated values from the applicable manufacturer, and independently verify against your actual installed hardware and firmware.

**Passing the schema/CI tests says nothing about fitness for use on a real printer.** No application to physical hardware is implemented or endorsed.
